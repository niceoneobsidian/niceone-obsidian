# Release and Versioning

OIS currently uses the existing 0.0.0 development version. Move to Semantic Versioning when release artifacts are established.

MAJOR means incompatible public contract changes; MINOR means backward-compatible capability additions; PATCH means backward-compatible fixes. Use pre-release identifiers for release candidates.

A release requires clean required CI, security scans, dependency-lock verification, SBOM, artifact attestation, capability-evidence review, deployment verification, rollback target, and a changelog entry.
