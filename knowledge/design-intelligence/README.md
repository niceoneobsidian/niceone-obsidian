# Knowledge Fabric

This directory contains curated, versioned design intelligence.

## Knowledge Types

- principles
- design systems
- brand rules
- typography
- color
- layout
- UI/UX
- visual styles
- audience and market context
- competitive evidence
- production specifications
- accessibility
- tool/model capability notes

Every knowledge item should preserve:

```text
identity
source
provenance
scope
confidence
version
status
relationships
review date
```

Knowledge is not runtime memory. Runtime observations belong to the evidence and memory subsystems.
